# Dados de Transferência

**Alterar Dados Bancários de Transferência**

- Acesse o menu (☰) no canto superior esquerdo
- Vá para Configurações
- Selecione a seção “Dados de Transferência”
- Digite os novos dados bancários e clique em Salvar
