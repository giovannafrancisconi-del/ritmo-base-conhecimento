# Colaboradores

Passo a Passo

- Acesse o menu (☰) no canto superior esquerdo
- Vá para Configurações
- Selecione a seção “Configurações de Colaboradores”
- Clica em “+” e preencha todos os campos para cadastrar o colaborador
- Nos três pontinhos é possível editar ou remover o colaborador
