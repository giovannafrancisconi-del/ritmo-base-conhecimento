# Adicionar/Excluir atleta do Grupo

Passo a Passo

- Menu (☰) > Atletas

- Pressione qualquer atleta para abrir a seleção

- Selecione os atletas desejados no che

- Clique “+” > Adicionar a um grupo

- Escolha o grupo > seleciona a seta para baixo do grupo desejado

- Automaticamente os atletas são adicionados e  aparece a lista

- Para excluir o atleta, basta clicar no “X”
