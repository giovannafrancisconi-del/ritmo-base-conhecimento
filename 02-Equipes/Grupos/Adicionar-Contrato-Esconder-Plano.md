# Adicionar Contrato / Esconder Plano

Passo a passo:

- Acesse o menu (☰) > Grupos
- Localize o grupo em questão e clique na setinha para baixo para visualizar mais
- Irá abrir a lista dos atletas nesse grupo e os três pontinhos
- Clique nos três pontinhos > Adicionar contrato
- Selecione o plano nos três pontinho no canto direto do plano escolhido

Aqui fará com que todos os atletas do grupo seja incluído/trocado para o contrato selecionado
