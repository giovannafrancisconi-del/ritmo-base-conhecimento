# CARD **de Recados dos Atletas

Dentro do Dash a escola consegue visualizar as mensagens recebidas dos atletas e responde-las:

Para responder o atleta, siga o passo a passo:

- Clique no ícone de Notificação (aviãozinho) no card de Recado do atleta

- Envie um recado ou notificação pelo próprio app

- Cliquem no ícone de Whatsapp para falar diretamente com responsável

- Cliquem no ícone "X” para fechar o recado
