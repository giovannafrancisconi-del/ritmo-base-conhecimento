# Perfil do Atleta

Aqui você encontra todas as informações do atleta como dados cadastrais, grupo, categoria, pertencente, faltas, documentos, notas, plano e faturas desse atleta.

Passo a passo:

- Menu (☰) > Atletas
- Selecionar o atleta para visualizar todas as informações do perfil
