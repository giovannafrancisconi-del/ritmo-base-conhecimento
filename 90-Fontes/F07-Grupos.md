# 👥 Grupos

> Registro documental consultado em 2026-10-20. Última edição informada pela fonte: 2026-05-12T14:44:43.021Z. Verificação nativa: unverified.

O conteúdo abaixo preserva as afirmações da fonte; linguagem de requisito não comprova implementação. Vídeos são referências, sem transcrição ou análise audiovisual.

Os grupos são criados para separas as turmas com seus respectivos dias e horários de treinos, realizar chamadas e enviar notificações

**Geral Grupos**

Criar um Grupo 

Passo a passo:

- Acesse o menu (☰) > Grupos
- Clique no ícone de "+" no canto superior direito
- Preencha as informações do grupo e atente-se às caixas de seleção que aparecerão
- Clique em Criar Grupo para concluir

⚠️ Atenção: A escola pode criar um grupo invisível para os alunos, permitindo selecionar determinados atletas para receberem uma notificação ou convocação “em massa”.

Editar Informações de um Grupo 

Passo a passo:

- Acesse o menu (☰) > Grupos
- Localize o grupo em questão e clique na setinha para baixo para visualizar mais
- Irá abrir a lista dos atletas nesse grupo e os três pontinhos
- Clique nos três pontinhos > Editar Grupo

⚠️ Atenção: Aqui é possível atrelas o grupo a um plano de contrato, adicionar documentos e faturas avulsas para todos os atletas do grupo.

Excluir um Grupo

Passo a passo:

- Acesse o menu (☰) > Grupos
- Localize o grupo que deseja excluir e clique na setinha para baixo para visualizar mais
- Irá abrir a lista dos atletas nesse grupo e os três pontinhos
- Clique nos três pontinhos > Remover Grupo

Exportar Atletas

Passo a passo:

- Acesse o menu (☰) > Grupos
- Localize o grupo em questão e clique na setinha para baixo para visualizar mais
- Irá abrir a lista dos atletas nesse grupo e os três pontinhos
- Clique nos três pontinhos > Exportar Atletas

Aqui é possível exportar um relatório para o seu e-mail com dados dos atletas deste grupo

Adicionar Contrato / Esconder Plano

Passo a passo:

- Acesse o menu (☰) > Grupos
- Localize o grupo em questão e clique na setinha para baixo para visualizar mais
- Irá abrir a lista dos atletas nesse grupo e os três pontinhos
- Clique nos três pontinhos > Adicionar contrato
- Selecione o plano nos três pontinho no canto direto do plano escolhido

Aqui fará com que todos os atletas do grupo seja incluído/trocado para o contrato selecionado

Adicionar Documentos

Passo a passo:

- Acesse o menu (☰) > Grupos
- Localize o grupo em questão e clique na setinha para baixo para visualizar mais
- Irá abrir a lista dos atletas nesse grupo e os três pontinhos
- Clique nos três pontinhos > Adicionar Documento

Aqui permite que ao adicionar o documento, seja solicitado aos atletas deste grupo o envio do documento selecionado. Exemplo: Atestado médico, documento, declaração, etc.

Adicionar Fatura Avulsa

Passo a passo:

- Acesse o menu (☰) > Grupos

- Localize o grupo em questão e clique na setinha para baixo para visualizar mais

- Irá abrir a lista dos atletas nesse grupo e os três pontinhos

- Clique nos três pontinhos > Adicionar Fatura

- Seleciona os atletas do grupo >Próximo 

- Preenche as informações da fatura avulsa > Criar fatura

Aqui permite gerar fatura avulsa para os atletas deste grupo.  Exemplo: Fatura referente á uniforma, taxa de jogo, arbitragem, campeonato, entre outras

Adicionar/Excluir atleta do Grupo

Passo a Passo

- Menu (☰) > Atletas

- Pressione qualquer atleta para abrir a seleção

- Selecione os atletas desejados no che

- Clique “+” > Adicionar a um grupo

- Escolha o grupo > seleciona a seta para baixo do grupo desejado

- Automaticamente os atletas são adicionados e  aparece a lista

- Para excluir o atleta, basta clicar no “X”
