# Fonte F23 — Decisão de configuração de vigência e premiação

Decisão informada pelo usuário para ampliar o protótipo de Configuração do Ranking de Equipes.

## Vigência da temporada

- A configuração deve permitir selecionar os meses que compõem a vigência.
- Exemplo declarado: janeiro a junho.

## Premiação

- Deve ser possível escolher se a premiação é válida para todo o Brasil ou para cada estado do Brasil.
- Para Brasil, deve haver descrição da premiação nacional.
- Para estado, deve ser possível selecionar o estado e descrever sua premiação.

Esta decisão não define posições premiadas, elegibilidade, desempate, periodicidade ou regras de entrega da premiação.
