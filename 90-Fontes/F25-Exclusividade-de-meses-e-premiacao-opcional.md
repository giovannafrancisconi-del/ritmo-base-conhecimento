# Fonte F25 — Exclusividade de meses e premiação opcional

Decisão informada pelo usuário para o protótipo de Configuração do Ranking de Equipes.

## Temporadas

- O ano deve ser selecionável para permitir configurar também anos futuros.
- Uma escola pode configurar diversas temporadas dentro do mesmo ano.
- Cada mês pode pertencer a somente uma temporada daquele ano.
- Exemplo: se a primeira temporada de 2027 contiver janeiro, fevereiro e março, março não pode ser incluído em outra temporada de 2027.
- A exclusividade é anual: a mesma referência de mês pode ser usada em um ano diferente.

## Premiação

- A configuração deve começar pela decisão de conceder ou não premiação.
- Quando a resposta for **não**, não há configuração adicional de premiação.
- Quando a resposta for **sim**, a escola seleciona a abrangência:
  - **Brasil inteiro:** registrar uma descrição única do prêmio.
  - **Por estado:** registrar uma descrição de prêmio para cada estado configurado.

Esta decisão não define posições premiadas, elegibilidade, desempate, entrega, persistência ou apuração em produção.
